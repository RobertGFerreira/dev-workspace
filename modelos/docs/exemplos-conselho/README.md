# Exemplos de Uso do Conselho de Decisão

Esta pasta contém exemplos práticos e anti-exemplos de uso do Conselho de Decisão.

## Conteúdo

| Arquivo | Descrição |
|:---|:---|
| `exemplo-sdd.md` | Exemplo completo de apoio do conselho à criação de SDD |
| `exemplo-testes.md` | Exemplo completo de derivação de testes |
| `exemplo-features.md` | Exemplo completo de expansão de features |
| `anti-exemplos.md` | Situações onde NÃO usar o conselho |
| `matriz-responsabilidades.md` | Matriz de responsabilidades entre conselho e agentes existentes |
| `RELATORIO_IMPLEMENTACAO.md` | Relatório final de implementação |

## Como usar

1. Identifique o tipo de demanda (SDD, testes, features)
2. Localize o exemplo correspondente
3. Adapte o formato ao contexto do seu projeto
4. Acione o conselho via `/conselho`
