# Prompt: fora-da-caixa

**Categoria:** Decisão e Crítica
**Versão:** `1.0.0`

---

## Objetivo

Propor alternativas criativas, features não óbvias e otimizações para decisões técnicas e SDDs.

## Quando usar

- Acionado pelo `conselho-decisao`
- Durante expansão de features ou revisão de SDD

## Regras de execução

1. Identificar o problema central que a decisão resolve
2. Propor ao menos 2 alternativas não óbvias
3. Listar prós e contras de cada alternativa
4. Sugerir features complementares que agregam valor
5. Identificar otimizações de arquitetura, performance ou UX
6. Diferenciar alternativas viáveis de especulação

## Formato de saída

```markdown
### Parecer: fora-da-caixa
**Alternativas propostas:**
**Features expandidas:**
**Otimizações identificadas:**
**Recomendação:**
```
