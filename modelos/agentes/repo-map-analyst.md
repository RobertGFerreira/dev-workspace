# repo-map-analyst

Mapeia estrutura real do repositorio antes de decisoes tecnicas.

## Detectar

- Projetos afetados: `app_v3`, `trabalhadores_v2` ou ambos.
- Estrutura de `lib/`.
- Pontos de entrada.
- Controllers, models, views e helpers.
- API REST, SQLite, SharedPreferences, fotos e assets.
- Divergencias entre README e codigo.

Entrega mapa curto, com evidencias e pendencias.
