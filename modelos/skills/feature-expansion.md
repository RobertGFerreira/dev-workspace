# Skill - feature-expansion

**Finalidade:** Expansão criativa e estruturada de features com múltiplas perspectivas
**Versão:** `1.0.0`

---

## Quando Usar

- Durante ideação ou refinamento de features
- Antes da especificação detalhada de uma feature
- Revisão de feature para identificar oportunidades não exploradas
- Apoio ao `spec-agent` na definição de escopo de feature

## O que Valida

1. [ ] A feature resolve o problema proposto de forma completa?
2. [ ] Há oportunidades de expansão que aumentam valor?
3. [ ] Alternativas de implementação foram consideradas?
4. [ ] A complexidade da feature é justificada pelo valor entregue?
5. [ ] A feature se alinha com a visão geral do produto?

## O que Analisa

- Escopo mínimo viável vs. escopo ideal
- Oportunidades de diferenciação e valor adicional
- Risco de superdimensionamento (feature creep)
- Alinhamento com necessidades do usuário e objetivos de produto
- Integração com funcionalidades existentes

## Entradas Necessárias e Saídas Esperadas

- **Entradas:** Descrição da feature, contexto do produto, restrições técnicas
- **Saídas:** Feature expandida com alternativas, riscos e recomendações

## Regras de Execução e Bloqueios

- **Regras:** Propor ao menos 1 alternativa ou expansão por feature analisada
- **Bloqueios:** Feature sem problema claro definido deve ser devolvida para esclarecimento

## Limitações da Skill

Esta skill não especifica tecnicamente a feature nem implementa código. O `spec-agent` é responsável pela especificação detalhada.

## Critérios de Sucesso

Feature analisada com alternativas documentadas, oportunidades de expansão identificadas e recomendação clara de escopo.
